# Protocol construction core

## Protocol header and version control

Record title, short title, sponsor/investigator, protocol identifier, version/date, amendment history, roles, funding, conflicts, registration status, ethics status, and data-controller responsibilities.

## Scientific question

- Describe the clinical problem and the decision the study will inform.
- Document the last search date, databases/platforms, full strategies, limits, deduplication, screening state, and overlap with recent reviews.
- Define population, intervention/exposure, comparator, outcome, time point, and setting.
- Name one primary objective. Label exploratory objectives as exploratory.

## Design and conduct

- State design, centre count, recruitment method, timeline, and unit of allocation/observation/analysis.
- Define inclusion and exclusion criteria that can be applied reproducibly.
- Describe intervention/exposure, comparator, co-interventions, adherence, crossover, contamination, and fidelity.
- Prespecify primary and secondary outcomes, instruments, scoring direction, time points, minimal important difference where defensible, and adverse-event collection.
- Do not treat KOOS as a generic total score. Prespecify the relevant KOOS subscale(s), designate one primary subscale/time point when confirmatory inference is intended, and document instrument version, language, visit window, scoring direction, and baseline adjustment.
- For randomized studies, document sequence generation, allocation concealment, implementation roles, blinding, emergency unblinding, and analysis population.
- For observational studies, define the target population, time zero, exposure assignment, confounders chosen from subject knowledge, follow-up, selection processes, and causal estimand if a causal effect is sought.
- For diagnostic studies, define index test, reference standard, positivity thresholds, participant flow, blinding, indeterminate results, and timing.
- For systematic reviews, define eligibility, information sources, complete search strategies, dual screening/extraction, effect measures, synthesis eligibility, risk of bias, certainty, and update plans.

## Sample size

Tie the calculation to the primary estimand, outcome distribution, effect or precision target, type-I error, power or confidence-width target, allocation ratio, clustering/repeated-measure correlation, attrition, and any multiplicity adjustment. Cite each numerical assumption. Provide sensitivity across plausible assumptions. Never substitute a universal number of participants.

## Ethics and transparency

Address consent or waiver, privacy, safety, compensation, vulnerable groups, post-trial care where relevant, monitoring, protocol deviations, registration timing, data/code sharing, publication policy, authorship, participant/public involvement, and dissemination of negative or inconclusive findings.

## Change control

Keep protocol and SAP versions immutable after approval. A dated amendment must state what changed, why, who approved it, whether outcome data were visible, and how the change affects interpretation.

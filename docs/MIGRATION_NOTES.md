The repository starts from a clean public-safe foundation. Candidate medical components may later be ported selectively from:

- `mohsamir7122/write` PR #1: Orthopaedic Research Workbench.
- `mohsamir7122/Research` PR #3: ACL, Scopus, and OpenAlex utilities.
